#Лабораторна робота № 6
Варіант 3 рівень 3
Ця програма аналізує, які міста можуть отримувати газ із наявних газосховищ через систему трубопроводів. Дані беруться з файлу data.txt, де вказані назви міст, газосховищ і маршрути трубопроводів. Програма читає ці дані, будує граф з'єднань і за допомогою обходу в глибину (DFS) визначає, які міста залишаються без постачання з кожного сховища.
