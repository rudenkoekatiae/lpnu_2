 #Лабораторна робота № 7
#Варіант 3 рівень 3
Основне завдання(lab_7) реалізує структуру даних Trie (префіксне дерево) для зберігання та пошуку слів. Можна додавати слова, шукати повні співпадіння (search) і перевіряти, чи існує слово з заданим префіксом (starts_with). В прикладі створюється Trie зі слів і демонструється робота пошуку та перевірки префіксів.
Додаткове завдання (filter_chats) перевіряє чати на наявність нецензурної лексики, автоматично замінює погані слова на замасковану версію (наприклад, shit → s**t), підраховує кількість порушень для кожного IP-адресу й блокує його на 12 годин після 5 порушень на день. Підтримується обробка чатів з файлу за ChatID (1–10) або ручне введення повідомлень. Результат зберігається у файлі blurred_chat_<ID>.txt, а бан-статус показується в логах.
